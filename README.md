# Arlo Wood - متجر إلكتروني للمنتجات الخشبية

متجر إلكتروني كامل متخصص في المنتجات الخشبية (أثاث، ديكور، هدايا، وطلبات مخصصة).

## المميزات

- عرض المنتجات مع فلترة وبحث
- سلة مشتريات تعمل بالكامل (محفوظة في المتصفح)
- صفحة طلب منتج خشبي **مخصص** (أبعاد + نوع خشب + ملاحظات)
- اختيار طريقة الدفع: فودافون كاش، إنستا باي، فوري، فيزا، أو طريقة أخرى
- تأكيد الطلب عبر **واتساب** على الرقم **01551277017**
- بعد إرسال الطلب: أنت بتحدد رسوم الشحن وتسأل العميل عن التأكيد، وبعدين تبدأ التجهيز
- تصميم متجاوب بألوان خشبية دافئة
- واجهة باللغة العربية (RTL)

## التقنيات

- Next.js 14+ (App Router) + TypeScript
- Tailwind CSS
- Zustand (إدارة السلة)
- Lucide Icons

## التشغيل المحلي

```bash
# تثبيت الحزم
npm install

# تشغيل السيرفر التطويري
npm run dev
```

افتح [http://localhost:3000](http://localhost:3000)

2. ادخل على [vercel.com](https://vercel.com)
3. Import المشروع
4. اضغط Deploy

## هيكل الصفحات

| المسار | الوصف |
|--------|------|
| `/` | الصفحة الرئيسية |
| `/products` | جميع المنتجات |
| `/products/[id]` | تفاصيل المنتج |
| `/custom-order` | طلب منتج خشبي مخصص |
| `/cart` | سلة المشتريات |
| `/checkout` | إتمام الطلب + اختيار الدفع |
| `/order-success` | تأكيد إرسال الطلب |
| `/about` | من نحن |
| `/contact` | تواصل معنا |
